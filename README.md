# Lua Table Editor

游戏策划 Lua 配置表编辑工具 —— 用 Excel 表格的方式可视化编辑 `.lua` 配置文件，支持多标签页、列固定、行键、筛选、填充柄、撤销/重做等。

基于 **Python + PySide6** 构建，可用 PyInstaller 打包为独立 exe。

## 功能特性

### 表格编辑（Excel 风格）
- 双击单元格编辑，`Enter` 确认并跳下一行，`Tab` 移动光标
- **填充柄**：选中区域右下角小方块向下拖拽填充 —— 支持同值填充、等差序列延续、循环模式
- **多选批量操作**：`Shift`/`Ctrl` 多选行，批量删除、批量同步行键
- 撤销/重做（`Ctrl+Z` / `Ctrl+Y`）
- 添加/删除数据行、批量添加多行、添加注释行、添加新列

### 行键支持（策划常用 `[key] = {...}` 格式）
- 完整识别并保留 Lua 表中的 `[key]` 行键，编辑/保存后保持格式
- **批量同步行键**：选中多行，一键将行键同步为各行的 `id` 值（覆盖式）
- **修复行键**：`Ctrl+Shift+K`，从 `id` 字段恢复缺失/错误的 `[key]=`，防止键值不一致

### 列固定（冻结）
- 表头右键 → 「📌 固定此列到左侧 / 右侧」，支持任意列左右固定
- 冻结列浮层与主表滚动同步、可独立调列宽、可右键取消固定
- 选中行列/交叉点高亮，方便对位核对

### 查找与筛选
- **查找**（`Ctrl+F`）：支持区分大小写、单列/全部列、上一个/下一个定位、结果计数
- **列筛选**：表头右键，支持 `等于` / `不等于` / `包含` / `不包含` 四种模式，可随时清除

### 工作区面板
- 左侧树形展示多个文件夹下的 `.lua` 文件，支持嵌套子目录
- 每个工作区文件夹可独立设置背景色；文件支持添加备注
- 右键：打开文件 / 在文件管理器中打开所在位置 / 刷新 / 移除文件夹

### 数据可靠性
- **后台线程加载**大表，界面不卡顿（状态栏显示进度动画）
- **自动刷新**：勾选后，已打开且**未被修改**的表会定时从磁盘重新加载（外部工具改表自动跟进）
- 手动刷新：`F5`
- 多标签页 + 最近文件，关闭有未保存修改时提示保存

### 支持的 Lua 表格式
| 格式 | 示例 |
|---|---|
| 匿名数组（最常用） | `ItemTable = {{ id=1, name="Sword" }}` |
| `[key] = {...}`（中文策划常用） | `[10001] = { id=10001, name="Sword" }` |
| `return {...}`（Lua 模块格式） | `return {{ id=1, value=100 }}` |
| `local` 变量声明 | `local ItemTable = {{ id=1 }}` |

解析器保留注释行、原始行格式与行键，保存时尽量最小化对原文件的改动。

## 安装与运行

需要 **Python 3.9+**（建议 3.10+）。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行（源码方式）
python lua_table_editor.py
```

或直接双击 **`run.bat`**（Windows）。

## 打包为独立 exe

```bash
build.bat
```

打包产物输出到 `dist\LuaTableEditor.exe`（PyInstaller 单文件模式）。

## 技术要点（简要）

- `LuaParser`：容错解析 Lua 表，保留注释/行键/原始文本，支持嵌套表与复杂值（引号、转义、嵌套括号）
- `LuaSerializer`：序列化回 Lua，未修改内容尽量保持原样，减少无效 diff
- `LuaTableModel` / `FilterProxyModel` / `LuaTableView`：Qt 模型/视图架构，筛选在代理层完成
- **冻结列**：每侧（左/右）用一个合并浮层 `QTableView` overlay 显示该侧所有冻结列，避免每列一个浮层导致的重绘开销
- **大表加载**：后台 `QThread` 解析，前台进度动画，防界面卡顿
- 未修改表定时自动刷新：比对磁盘 `mtime`，仅在外部变更时静默重载
